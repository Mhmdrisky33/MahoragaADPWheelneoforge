# 魔虚罗 · Mahoraga

《咒术回战》主题的 Minecraft 模组 —— **玩家版魔虚罗**。

> 「八握剑·异戒神将」—— 挨过一次，就再也伤不到你。

## 玩法核心：适应

**挨过一次的攻击，就再也伤不到你。** 三条轨道各自独立计算。

### 一、防御适应 · 免伤

按**伤害类型**记录。40+ 种伤害类型可以各自练到完全免疫：

近战 / 箭矢 / 三叉戟 / 投掷物 / 火球 / 凋灵之首 / 龙息 / 音波 / 爆炸 / 雷击 /
火焰 / 着火 / 岩浆 / 岩浆块 / 冰冻 / 溺水 / 饥饿 / 凋零 / 魔法 / 虚空 / 坠落 /
撞墙 / 落石 / 铁砧 / 石锥 / 仙人掌 / 甜浆果 / 蜂刺 / 荆棘 / 挤压 / 窒息 …

**25% 免四分之一 ｜ 75% 免四分之三 ｜ 100% 完全免疫**

### 二、攻击适应 · 打什么学什么

按**生物种类**记录，五档层层累加：

| 进度 | 效果 |
|---|---|
| 100% | 附加法术伤害（无视护甲） |
| 200% | 升为**真实伤害**（护甲 / 附魔 / 药水 / 伤害吸收全无效） |
| 250% | 解锁「**剑气**」—— 攻击甩出远距离斩击，挥空也算 |
| 500% | 追加「50 点 + 目标最大生命 20%」的重击 |
| 1000% | 「**空间斩**」—— 无条件抹除 |

学会之后**永久有效**，掉进度也不会忘。
另有四条「偷学」剑气路径：骷髅攻击 100% / 幻翼防御 100% / 被投掷物打中 100% / 任意生物攻击 250%。

### 三、日常适应 · 11 条

不用挨打也不用打人 —— 一直做某件事，身体自己就适应了：

持续挖掘 / 持续奔跑 / 持续跳跃 / 浸泡水中 / 浸泡岩浆 / 身处黑暗 / 身处洞穴 /
进食 / 附魔 / 钓鱼 / 投掷物品

## 洞悉 · 夺走它的杀招

| 猪灵蛮兵 | 护甲翻倍 |
| 卫道士 | 盾牌永远不会被击破 |
| 疣猪兽 / 劫掠兽 / 恶魂 | 永远不会被击退 |
| 唤魔者 | 无视不死图腾 |
| 末影人 | 受伤时短距瞬移 |

## 解析 · 独特破解

打中 **100 血以上**的生物会当场开启解析，读出：

生命 / 护甲 / 攻击力 / 是不是首领 / 生物标签 / **有没有锁血** / 会不会飞 / 会不会瞬移

然后从它的机制里**抽出破解**（12 种）：
百分比伤害 / 真实伤害 / 削减生命上限 / 削减护甲 / 削减攻击力 / 禁止治疗 /
流血不止 / 虚弱标记 / 穿甲重击 / 禁锢 / 禁止传送 / 清除召唤物 / 停滞领域

## 退魔之剑

拿到法轮那天，它从你体内长出来。

**右键**释放特殊能力，**潜行 + 右键**切换：

瞬移 · 空间斩 · 亡灵斩杀 · 防御反击 · 万能工具

- 适应了**火焰** → 剑刃烧红，攻击附带点燃
- 适应了**寒冷** → 剑刃结霜，攻击附带迟缓
- 适应了**雷击** → 攻击引雷（无视天气）

---

## 法轮

**末地城的宝箱**里能找到「退魔法轮」。戴上之后：

- **+10 生命 · +3 护甲 · 二段跳**
- 左上角出现 **HUD**，实时显示正在适应的项目与进度

## 安装

1. Minecraft **1.20.1** + Forge **47.4.22** 或更高
2. 装上前置 [GeckoLib](https://www.curseforge.com/minecraft/mc-mods/geckolib)（**4.8.4+**）
3. 两个 jar 一起丢进 `mods/` 目录

## 命令

| 命令 | 作用 |
|---|---|
| `/mahoraga` | 查看当前适应状态 |
| `/mahoraga reset` | 清空全部适应进度 |
| `/mahoraga set <轨道> <键> <百分比>` | 直接设定某条适应（调试用） |
| `/mahoraga wheel reset` | 摘掉法轮（回到完全原版状态） |
